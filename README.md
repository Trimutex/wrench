WRangle ENtire Config Home

A simple application to handle all of your Linux configuration needs.

> [!CAUTION]

> Continued development on this project has been moved to [here](https://lab.trianta.dev/trianta/wrench)

## build

Build the project using:

```console
cmake -B build -S .
cmake --build build
```

## running

The program is now in the build directory and can be run with

```console
./build/wrench
```
